## Development Environment

Project Victorious is developed using a modern AI-native development workflow.

Development Stack

- Claude Code — Primary implementation environment
- Mutagent (Helix ADL) — Agentic Development Lifecycle for specification, build, evaluation, diagnosis, and optimization
- Git & GitHub — Version control
- VS Code — Primary IDE

These technologies are used during development and are not part of the runtime architecture of Project Victorious.



A simple table like this:

Layer	Technology	Purpose

Backend	FastAPI	Business Logic
AI	LangGraph	Agent Workflow
LLM	Gemini	Reasoning
Database	PostgreSQL	Persistent Storage
Vector DB	ChromaDB	Semantic Memory
